# 11 — UX States Catalog

Defined once here; every page spec (`05`–`10`) references entries by name rather than redefining them. Each state includes: what's shown, the tone of any copy, and the recovery action.

## Loading states

| State                       | Shown as                                                                                                                                                                                                                             | Notes                                                                                         |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| **Skeleton — grid/list**    | Grey (`color-bg-sunken`) blocks matching the real component's shape (Product Card image + 2 text bars; list row shapes for orders/addresses), subtle shimmer sweep left→right, `duration-slow`, looping only while genuinely loading | Never a spinner for grid content — skeletons preserve layout, preventing content jump on load |
| **Skeleton — PDP**          | Gallery block, title bar, price bar, two button-shaped bars                                                                                                                                                                          | Same shimmer treatment                                                                        |
| **Inline button loading**   | Spinner replaces label, button width fixed, disabled                                                                                                                                                                                 | Per Button component `03`                                                                     |
| **Page-level initial load** | Skeleton of the destination layout (not a generic spinner) whenever feasible; a centered spinner only for states with no meaningful skeleton shape (e.g. payment processing)                                                         |                                                                                               |
| **Load more (pagination)**  | Small centered spinner beneath existing content, existing content stays fully interactive                                                                                                                                            |                                                                                               |
| **Search in-flight**        | Spinner replaces the search icon inside the input                                                                                                                                                                                    | See `05` §5.4                                                                                 |

## Empty states

Each empty state = icon or simple line illustration (restrained, single-color line art matching `color-text-tertiary`, never a busy illustration) + `type-heading-m` headline + one `type-body-m` supporting line + one clear action.

| Context                            | Headline                                                            | Supporting line                                      | Action                                                                                                                                               |
| ---------------------------------- | ------------------------------------------------------------------- | ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Empty cart**                     | "Your bag is empty"                                                 | "Everything you add will show up here."              | `primary` "Start Shopping" → `/shop`                                                                                                                 |
| **Empty wishlist**                 | "Nothing saved yet"                                                 | "Tap the heart on any product to save it for later." | `primary` "Explore the Collection" → `/shop`                                                                                                         |
| **No search results**              | "No results for \"[query]\""                                        | "Check the spelling, or try a broader term."         | Show 3–4 Popular Search chips + a small "Browse categories" grid beneath, as an alternative path — per brief's "helpful alternative recommendations" |     |
| **No products after filtering**    | "No items match these filters"                                      | "Try removing a filter to see more."                 | `secondary` "Clear all filters"                                                                                                                      |
| **Empty collection (coming soon)** | "This collection is on its way"                                     | "Check back soon, or explore what's live now."       | `secondary` "Shop New Arrivals"                                                                                                                      |
| **Empty order history**            | "No orders yet"                                                     | "Your past orders will appear here."                 | `primary` "Start Shopping"                                                                                                                           |
| **Empty recently-viewed**          | _(section omitted entirely — no visible empty state; see PDP `06`)_ |                                                      |                                                                                                                                                      |
| **No FAQ results**                 | "No matching questions"                                             | "Try a different term, or contact support directly." | Link to `/contact`                                                                                                                                   |

## Error / unavailable states

| Context                                                                       | Behavior                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ----------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Product out of stock**                                                      | See PDP §06 — page renders fully, purchase controls replaced with Notify Me                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Product coming soon**                                                       | See PDP §06                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Item unavailable at checkout** (went out of stock between cart and payment) | Inline Alert (component `03`, warning tint) on the affected Cart/Checkout line item: "This item just sold out." with `secondary` "Remove" action; price breakdown recalculates immediately; user is not blocked from checking out with remaining items                                                                                                                                                                                                                           |
| **Failed payment**                                                            | Payment section re-expands (checkout stays on the same page/state — no redirect to an error page), non-dismissible Alert (error tint) above the Payment fields with the specific reason if the processor provides one ("Card declined — try a different payment method"), generic fallback otherwise ("Something went wrong processing your payment — please try again"); Place Order button returns to default (non-loading) state; all previously entered fields remain filled |
| **Payment processing**                                                        | Place Order button `loading` state; if processing exceeds ~5s, an inline line appears beneath it: "This is taking a little longer than usual — please don't close this page." (Prevents the user assuming it's frozen and retrying, which risks duplicate charges.)                                                                                                                                                                                                              |
| **Order failed (post-payment, e.g. system error before confirmation)**        | Dedicated inline error state in place of confirmation: "We hit a snag confirming your order." + order/payment status reassurance ("Your payment has not been charged" or "Your payment was received — we're finalizing your order and will email confirmation shortly," whichever is factually true) + `/contact` link with reference number                                                                                                                                     |
| **Network error** (any page, request fails)                                   | Inline Alert (error tint) at the point of failure ("Couldn't load this — check your connection") with a `secondary` "Retry" action; never a full white/blank screen                                                                                                                                                                                                                                                                                                              |
| **Invalid coupon**                                                            | Inline error directly beneath the coupon input (Input component's error state): "This code isn't valid" or, if determinable, more specific ("This code has expired" / "This code isn't valid for the items in your bag")                                                                                                                                                                                                                                                         |
| **Invalid address**                                                           | Field-level Input error states (component `03`) on the specific invalid fields, plus, if an address-verification service suggests a correction, a non-blocking inline suggestion: "Did you mean: [suggested address]?" with Accept/Keep as entered options                                                                                                                                                                                                                       |
| **Session expired** (e.g. checkout session timed out)                         | Non-blocking Alert at the top of the affected page: "Your session expired — please review your details." Cart contents are preserved if technically feasible; if not, user is returned to Cart (not an error page) with a clear explanation, never silently emptied without a message                                                                                                                                                                                            |
| **Form validation** (any form)                                                | Inline, on-blur, per Input component `03` — never a top-of-page summary list of all errors as the _only_ signal; each error lives next to its field                                                                                                                                                                                                                                                                                                                              |

## Success / confirmation states

| Context                    | Behavior                                                                                                                                                                                                                                                                                                                                                        |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Add to cart**            | Toast (component `03`): "[Product name] added to your bag" + "View cart" action + cart-count increment animation (`13`)                                                                                                                                                                                                                                         |
| **Wishlist add**           | Toast: "Added to your wishlist" (or no toast at all if the heart-fill animation alone is judged sufficient feedback — heart animation is required either way, toast is a judgment call left to implementation, but if included, keep it brief and skip the "View wishlist" action unless requested, to avoid toast fatigue since this action is high-frequency) |
| **Wishlist remove**        | Toast: "Removed from your wishlist" + "Undo" action                                                                                                                                                                                                                                                                                                             |
| **Cart item removed**      | Toast: "Removed — Undo" (4s window)                                                                                                                                                                                                                                                                                                                             |
| **Newsletter signup**      | Inline success replaces the form: checkmark + "You're on the list." — no toast (this is a standalone in-page moment, not a background action)                                                                                                                                                                                                                   |
| **Contact form submitted** | Inline success replaces the form: checkmark + "Message sent — we'll get back to you within 24 hours."                                                                                                                                                                                                                                                           |
| **Order placed**           | Full Order Confirmation page (`08` §8.1) — the highest-weight success state in the system                                                                                                                                                                                                                                                                       |
| **Address saved**          | Toast: "Address saved"                                                                                                                                                                                                                                                                                                                                          |
| **Preference toggled**     | Toast: "Preferences updated" (debounced if multiple toggles fire quickly — one toast, not one per toggle)                                                                                                                                                                                                                                                       |
| **Password changed**       | Inline success in the modal/sheet before it closes: checkmark + "Password updated," auto-dismiss after ~1.5s                                                                                                                                                                                                                                                    |
